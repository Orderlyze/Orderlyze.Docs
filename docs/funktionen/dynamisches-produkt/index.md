# Dynamisches Produkt

Ein dynamisches Produkt ist ein **Einmalprodukt** mit frei wählbarem Namen, Menge und Preis. Es wird nicht im Stammdaten-Bestand gespeichert, sondern nur für die aktuelle Rechnung erzeugt.

:::info Voraussetzung
Dynamische Produkte müssen unter **Weitere Einstellungen** aktiviert sein. Erscheint das Plus-Symbol nicht, prüfe ob die Einstellungen mit der App synchronisiert sind.
:::

## So legst du ein dynamisches Produkt an

1. Im Reiter **Hinzufügen** auf das **Plus-Symbol** unten rechts tippen
2. Im Popup eingeben:
   - **Menge** (frei wählbar)
   - **Produktname** (frei wählbar)
   - **Preis** (frei wählbar)
3. Den passenden **Mehrwertsteuersatz** auswählen
4. Eine **Produktkategorie** zuweisen
5. Speichern

## Ergebnis prüfen

Wechsle in den **Rechnungs-Tab** — das eben angelegte Produkt erscheint dort als Position der aktuellen Rechnung.

<img src="/screenshots/funktionen/dynamisches-produkt/3.jpg" alt="Im Rechnungs-Tab" width="320" />

:::tip
Praktisch z.B. für Tagespreise, Sondergerichte oder Sammelpositionen, die du nicht extra als Stammdaten anlegen willst.
:::
