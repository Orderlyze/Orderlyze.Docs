# Dynamisches Produkt

Ein **dynamisches Produkt** ist ein Produkt, dessen Preis erst bei der Bestellung festgelegt wird — der Mitarbeiter gibt den Betrag direkt im Bonier-Bildschirm ein. Praktisch z.B. für Sondergerichte, Tagespreise oder Sammelpositionen.
