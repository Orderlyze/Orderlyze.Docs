# Steuer ändern

Die Mehrwertsteuersätze einzelner Produkte oder ganzer Kategorien können nachträglich angepasst werden — z.B. bei einer Steuerreform oder bei Wechsel zwischen In-Haus- und Außer-Haus-Steuersatz.

Vollständige Schritt-für-Schritt-Anleitung: [orderlyze.com/steuer-aendern](https://www.orderlyze.com/steuer-aendern)
:::
