# Rechnungen nachträglich bearbeiten / stornieren

Bereits abgeschlossene Rechnungen können nachträglich storniert oder korrigiert werden — z.B. wenn ein Produkt falsch boniert wurde oder eine Rückgabe erfolgt. Die Original-Rechnung bleibt aus Compliance-Gründen erhalten; die Korrektur wird als neuer Vorgang protokolliert.

:::info
Vollständige Schritt-für-Schritt-Anleitung: [orderlyze.com/rechnungen-bearbeiten](https://www.orderlyze.com/rechnungen-bearbeiten)
:::
