# Pfand

Pfand-Beträge (z.B. auf Mehrwegflaschen oder -gefäße) können als eigene Positionen in Orderlyze hinterlegt werden. Beim Verkauf wird der Pfand mitgebucht, bei Rückgabe wieder ausgezahlt.

:::info
Vollständige Schritt-für-Schritt-Anleitung: [orderlyze.com/pfand](https://www.orderlyze.com/pfand)
:::
