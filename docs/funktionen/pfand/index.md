# Pfand

Pfandbeträge (z.B. auf Mehrwegflaschen oder -gefäße) werden in Orderlyze über zwei spezielle Produkte abgebildet — eines für die Ausgabe (positiver Preis), eines für die Rückgabe (negativer Preis).

## Einrichtung

1. Orderlyze App öffnen → Menü → **Verwaltung**
2. Im Menü **Verwaltung** auf **Kategorien** tippen
3. Eine neue Kategorie namens **Pfand** anlegen
4. Im Menü **Verwaltung** auf **Produkte** tippen
5. Ein Produkt mit dem Namen **Pfand** anlegen
   - Beliebigen Preis eintragen (z.B. 2 €)
   - Der Kategorie **Pfand** zuordnen
6. Ein zweites Produkt mit dem Namen **Pfand retour** anlegen
   - **Negativen Preis** eintragen (z.B. -2 €)
   - Der Kategorie **Pfand** zuordnen

## Anwendung

Beim Erstellen einer Rechnung das Produkt **Pfand** für die Ausgabe bzw. **Pfand retour** für die Rückgabe hinzufügen. Der jeweilige Betrag wird automatisch in der Rechnungs-Summe berücksichtigt.
