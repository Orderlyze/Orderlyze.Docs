# Abholung

Für Abhol- bzw. Außer-Haus-Bestellungen gilt in vielen Ländern ein reduzierter Mehrwertsteuersatz. In Orderlyze lässt sich dieser pro Kategorie hinterlegen und beim Bezahlen direkt anwenden.

## Einrichtung

1. Orderlyze App öffnen → Menü → **Verwaltung**
2. **Weitere Einstellungen** → **Allgemein**
3. Im Bereich **Zahlungsprozess** den Eintrag aufklappen
4. Den Schalter **Außer-Haus-Funktion** aktivieren
5. Im Menü **Verwaltung** in **Produktkategorien** wechseln
6. Eine Kategorie mit Abhol-Produkten auswählen und auf das **Bearbeiten-Symbol** tippen
7. Im Feld **Mehrwertsteuer (Abholung)** den abweichenden Steuersatz eintragen (z.B. 7 %)
8. Schritt 7 für alle relevanten Kategorien wiederholen

![Einrichtung](/screenshots/funktionen/abholung/1.jpg)

## Beim Bezahlen anwenden

1. Auf **Gesamt bezahlen** oder **Getrennt bezahlen** tippen
2. Statt **OK** auf **Mitnahme** tippen

Die Rechnung wird automatisch mit den hinterlegten Außer-Haus-Steuersätzen erstellt.
