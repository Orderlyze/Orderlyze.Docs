# Tischplan gestalten

Der Tischplan wird in der Orderlyze App auf Tablet oder Smartphone gestaltet — Tische und Trennlinien werden per Drag-&-Drop frei positioniert.

## Tische hinzufügen

1. Oben links auf das **Menü-Symbol** tippen
2. **Tischplan gestalten** auswählen
3. Unten rechts auf das **Stuhl-Symbol** tippen
4. Im Popup den **Tischnamen** eingeben
5. **Speichern** antippen
6. Den neu erstellten Tisch an die gewünschte Position ziehen

## Tische bearbeiten und löschen

1. Den gewünschten Tisch antippen
2. Im Bearbeiten-Fenster lassen sich **Name**, **Breite**, **Höhe** und **Rotation** anpassen
3. Mit **Fertig** Änderungen übernehmen
4. Mit **Löschen** den Tisch entfernen (optional)

<img src="/screenshots/funktionen/tischplan/4.png" alt="Tisch bearbeiten" width="320" />

---

## Trennlinien hinzufügen

1. Unten rechts auf den **blauen Button mit weißer Linie** tippen
2. Eine neue Trennlinie wird automatisch oben links eingefügt
3. Die Trennlinie an die gewünschte Position ziehen

<img src="/screenshots/funktionen/tischplan/5.png" alt="Trennlinie hinzufügen" width="320" />

---

## Trennlinien bearbeiten und löschen

1. Die gewünschte Trennlinie antippen
2. **Breite**, **Höhe** und **Ausrichtung** anpassen
3. Mit **Fertig** bestätigen
4. Mit **Löschen** die Trennlinie entfernen (optional)
