# Tischplan gestalten

Der Tischplan wird direkt in der Orderlyze App auf Tablet oder Smartphone gestaltet (Seitenmenü → *Tischplan gestalten*). Tische lassen sich per Drag-&-Drop positionieren, in der Größe verändern und Räumen zuordnen.

:::info
Vollständige Schritt-für-Schritt-Anleitung: [orderlyze.com/tischplan](https://www.orderlyze.com/tischplan)
:::
