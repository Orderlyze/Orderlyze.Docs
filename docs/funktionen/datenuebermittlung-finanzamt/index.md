# Datenübermittlung Finanzamt (Deutschland)

In Deutschland sind elektronische Kassen verpflichtet, ihre Daten an das Finanzamt zu melden. Diese Schritte erledigst du einmalig im Orderlyze Web-Portal.

## 1. Einstellungen öffnen

Logge dich im Orderlyze Web-Portal ([web.orderlyze.com](https://web.orderlyze.com)) ein. Klicke oben rechts auf das **Benutzersymbol** und wähle **Einstellungen**.

![Einstellungen öffnen](/screenshots/funktionen/datenuebermittlung-finanzamt/1.png)

## 2. Signaturanbieter (TSE) wählen

Im linken Menü auf **SIGNATURANBIETER(TSE)** klicken.

![Signaturanbieter TSE](/screenshots/funktionen/datenuebermittlung-finanzamt/2.png)

## 3. Daten an Finanzamt übermitteln

Klicke auf den Button **Daten an Finanzamt übermitteln**.

![Übermittlungs-Formular](/screenshots/funktionen/datenuebermittlung-finanzamt/3.png)

## 4. Stammdaten ausfüllen

Trage in das Formular die geforderten Unternehmensdaten ein:

- **Juristische Person** auswählen, falls es sich z.B. um eine GmbH handelt
- **Identifikationsnummer** — die elektronische Steuernummer aus dem ELSTER-Portal
- **Registrierte Firmenadresse** — die Hauptadresse des Unternehmens (nicht die Filialadresse)

## 5. ELSTER-Steuernummer ermitteln

Falls du die ELSTER-Steuernummer nicht parat hast, kannst du sie online berechnen:

1. Öffne [ueberbrueckungshilfe-unternehmen.de/Steuernummer-Umrechner](https://www.ueberbrueckungshilfe-unternehmen.de/DE/Infothek/Steuernummer-Umrechner/steuernummer-umrechner.html)
2. Bundesland und Steuernummer eingeben
3. Auf **Umrechnen** klicken
4. Die berechnete ELSTER-Steuernummer in das Orderlyze-Formular kopieren

![ELSTER-Umrechner](/screenshots/funktionen/datenuebermittlung-finanzamt/4.png)

Mit **Weiter** zum nächsten Schritt.

## 6. Filialadresse erfassen

Im nächsten Schritt die Adresse der **Filiale** (Betriebsstätte) eintragen. Falls Filial- und Firmenadresse identisch sind, einfach dieselben Daten verwenden.

![Filialadresse](/screenshots/funktionen/datenuebermittlung-finanzamt/5.png)

## 7. Bestätigung akzeptieren

Den Bestätigungs-Dialog mit **Akzeptieren** quittieren.

![Akzeptieren](/screenshots/funktionen/datenuebermittlung-finanzamt/6.png)

## 8. Übermittlung auslösen

Klick auf **Daten an Finanzamt übermitteln**. Anschließend kannst du das Bestätigungs-PDF herunterladen und für deine Unterlagen speichern.

![Übermittlung & Bestätigung](/screenshots/funktionen/datenuebermittlung-finanzamt/7.png)

:::info
Die Übermittlung muss nur einmalig vorgenommen werden. Bei einem Wechsel der Stammdaten (Adresse, Steuernummer) ist eine erneute Meldung erforderlich.
:::
