# Datenübermittlung Finanzamt (Deutschland)

Für deutsche Betriebe stellt Orderlyze die Kassendaten in den vom Finanzamt vorgeschriebenen Formaten (DSFinV-K, TSE-Daten) bereit. Diese werden im Rahmen einer Kassen-Nachschau oder Betriebsprüfung vom Finanzamt verlangt.

:::info
Die vollständige Schritt-für-Schritt-Anleitung findest du auf der Orderlyze-Webseite: [orderlyze.com/uebermittlung-finanzamt](https://www.orderlyze.com/uebermittlung-finanzamt)
:::
