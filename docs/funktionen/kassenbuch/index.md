# Kassenbuch

Im Kassenbuch werden alle Bareinnahmen und Barausgaben tagesgenau erfasst. Es dient als Nachweis für die Steuer und ist Teil der ordnungsgemäßen Buchführung.

Vollständige Schritt-für-Schritt-Anleitung: [orderlyze.com/kassenbuch](https://www.orderlyze.com/kassenbuch)
:::
