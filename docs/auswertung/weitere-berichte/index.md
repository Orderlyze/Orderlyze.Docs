# Weitere Berichte

In der linken Sidebar findest du unter **Weitere Berichte** sieben spezialisierte Auswertungen. Pro Bericht gibt es eine eigene Seite mit Screenshot der Sidebar-Position und Übersicht über die Spalten:

- [Rechnungsbericht](rechnungsbericht)
- [Tagesumsatzbericht](tagesumsatzbericht)
- [Produktbericht](produktbericht)
- [Zahlungsartenbericht](zahlungsartenbericht)
- [Kategoriebericht](kategoriebericht)
- [Stornobericht](stornobericht)
- [Benutzerbericht](benutzerbericht)

Alle Berichte folgen demselben Bedienschema:

1. Bericht in der Sidebar wählen
2. Zeitraum festlegen (für einen einzelnen Tag das Datum zweimal anklicken)
3. **PDF** oder **CSV** herunterladen
