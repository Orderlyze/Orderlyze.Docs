# Berichte

Über die Auswertungen in der linken Sidebar erstellen Sie Berichte für Ihre Buchhaltung und Steuerberatung. Die häufigsten Berichte sind in einer eigenen Sidebar-Sektion aufgeführt, weitere finden Sie unter [Weitere Berichte](/auswertung/weitere-berichte).

## So erstellst du einen Monatsbericht

1. In der linken Sidebar auf **Monatsbericht** klicken
2. Den gewünschten **Monat** wählen
3. Der Bericht wird automatisch als **PDF** heruntergeladen — bereit zum Weiterleiten an die Steuerberatung

<BrowserFrame src="/screenshots/berichte/monatsbericht.png" alt="Monatsbericht" />

## So erstellst du einen Jahresbericht

1. In der linken Sidebar auf **Jahresbericht** klicken
2. Das gewünschte **Jahr** wählen
3. Auf den blauen **Herunterladen**-Button klicken
4. Der Bericht wird automatisch als **PDF** heruntergeladen

<BrowserFrame src="/screenshots/berichte/jahresbericht.png" alt="Jahresbericht" />

## Weitere Berichte

Unter **Weitere Berichte** in der Sidebar finden Sie spezialisierte Auswertungen — z.B. zu Rechnungen, Produkten, Kategorien, Zahlungsarten, Stornierungen oder pro Benutzer. Sie folgen alle demselben Schema:

1. Bericht in der Sidebar auswählen
2. **Zeitraum** festlegen (für einen einzelnen Tag das Datum zweimal anklicken)
3. **PDF** oder **CSV** herunterladen

Eine ausführliche Beschreibung der einzelnen Berichte finden Sie unter [Weitere Berichte](/auswertung/weitere-berichte).
