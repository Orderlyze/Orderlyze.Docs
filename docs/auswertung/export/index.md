# Datenexport

**Navigation:** Auswertungen → Datenexporte

In der Sidebar finden Sie unter **Datenexporte** die Unterpunkte **Download Center**, **Datev Export**, **BMD Export** und **RZL Export**.

Orderlyze unterstützt verschiedene Exportformate für die Buchhaltung.

## DATEV Export

<BrowserFrame src="/screenshots/export/datev.png" alt="DATEV Export" />

DATEV ist das meistgenutzte Buchhaltungsformat in Deutschland und Österreich.

### Einrichtung

1. **Beraternummer** eingeben (von Ihrem Steuerberater)
2. **Mandantennummer** eingeben
3. **Geschäftsjahr-Start** festlegen (Format: dd.mm)
4. **Speichern** klicken

### Export durchführen

1. Datumsbereich wählen (von - bis)
2. **Download** klicken
3. CSV-Datei wird erstellt und erscheint im Download Center

:::tip
Die exportierte CSV-Datei kann direkt in DATEV importiert werden.
:::

## BMD Export

<BrowserFrame src="/screenshots/export/bmd.png" alt="BMD Export" />

BMD ist eine österreichische Buchhaltungssoftware.

1. Zeitraum wählen
2. **Export starten**
3. Datei herunterladen

## RZL Export

<BrowserFrame src="/screenshots/export/rzl.png" alt="RZL Export" />

RZL ist eine weitere österreichische Buchhaltungslösung.

1. Zeitraum wählen
2. **Export starten**
3. Datei herunterladen

## Download Center

Alle erstellten Exporte werden im Download Center gespeichert und können dort erneut heruntergeladen werden. Das Download-Center zeigt:

- Dateiname
- Benutzername
- Typ (DATEV, BMD, RZL)
- Status
- Erstellungsdatum
- Letzte Änderung
- Fehlermeldungen (falls vorhanden)
