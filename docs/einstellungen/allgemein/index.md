# Einstellungen

**Navigation:** Verwaltung → Weitere Einstellungen

![Einstellungen Übersicht](/screenshots/admin/einstellungen-allgemein-uebersicht.png)

Die Einstellungen sind in drei Bereiche unterteilt:
- **Allgemein** - Allgemeine Systemeinstellungen
- **Benutzer** - Benutzerindividuelle Einstellungen
- **Küche** - Küchenspezifische Einstellungen

---

## Allgemeine Einstellungen

**Navigation:** Weitere Einstellungen → Allgemein

Hier konfigurieren Sie systemweite Einstellungen, die für alle Benutzer gelten. Die Einstellungen sind in verschiedene Kategorien unterteilt.

### Menüpunkte in der App

![Menüpunkte in der App](/screenshots/admin/einstellungen-menuepunkte.png)

| Einstellung | Beschreibung |
|-------------|--------------|
| Einstellungen im Menü der App | Zeigt den Einstellungen-Menüpunkt in der mobilen App an |
| Bankterminal in Einstellungen der App | Aktiviert Bankterminal-Optionen in den App-Einstellungen |

### Hauptfunktionen

![Hauptfunktionen](/screenshots/admin/einstellungen-hauptfunktionen.png)

| Einstellung | Beschreibung |
|-------------|--------------|
| Gängesystem | Aktiviert das Gänge-Feature für mehrgängige Menüs. Ermöglicht die Zuordnung von Produkten zu Gängen (Vorspeise, Hauptgang, etc.) |
| Stammkundensystem | Ermöglicht Stammkunden-Verwaltung und Kundenbindung |
| Gutscheinsystem | Aktiviert Gutscheine und Rabatte für Verkäufe |
| Onlineshop | Aktiviert die Onlineshop-Integration für Online-Bestellungen |
| Tagesabschluss | Aktiviert die Tagesabschluss-Funktion für die tägliche Kassenabrechnung |

### Zahlungsprozess

## Benutzer-Einstellungen

**Navigation:** Weitere Einstellungen → Benutzer

![Benutzer Einstellungen](/screenshots/admin/einstellungen-benutzer-uebersicht.png)

Hier konfigurieren Sie individuelle Einstellungen pro Benutzer. Wählen Sie zuerst einen Benutzer aus dem Dropdown-Menü oben.

Die Kategorien entsprechen den allgemeinen Einstellungen, aber die Werte gelten nur für den ausgewählten Benutzer:

- **Menüpunkte in der App** - Welche Menüpunkte dieser Benutzer sieht
- **Zahlungsprozess** - Benutzerindividuelle Zahlungsoptionen
- **Produkte bonieren** - Individuelle Boniereinstellungen
- **Umsatzauswertung** - Welche Berichte der Benutzer sehen darf
- **Sonstige** - Weitere benutzerspezifische Optionen

:::tip
Benutzer-Einstellungen überschreiben die allgemeinen Einstellungen für den jeweiligen Benutzer.
:::

## Küchen-Einstellungen

**Navigation:** Weitere Einstellungen → Küche

![Küchen Einstellungen](/screenshots/admin/einstellungen-kueche-kuechenbons.png)

Hier konfigurieren Sie alle Einstellungen für den Küchenbetrieb und die Küchendrucker.

### Küchenbons

| Einstellung | Beschreibung |
|-------------|--------------|
| Storno Belege Drucken | Druckt Stornierungen auf dem Küchenbon |
| Cut nach jeden Gang | Schneidet den Bon nach jedem Gang ab |
| Bestellungen automatisch senden | Sendet Bestellungen automatisch ohne manuelle Bestätigung |
| Küchenzettel Schriftgröße | Small oder Large - Größe des Textes auf Küchenbons |
| Abstand vor der Bestellung | Leerraum vor dem Bestelltext (No spacing bis Extra large) |
| Abstand nach der Bestellung | Leerraum nach dem Bestelltext (No spacing bis Extra large) |
| Tisch/Kunden Transfer Belege drucken | Druckt einen Bon bei Tisch- oder Kundenwechsel |

### Druckerzuordnung

Für jeden Küchendrucker können Sie konfigurieren:

1. **Küchenbons drucken** - Aktiviert oder deaktiviert den Drucker für Küchenbons
2. **Kategoriezuordnung** - Welche Produktkategorien an diesen Drucker gesendet werden

:::tip
Ordnen Sie Kategorien sinnvoll zu: z.B. "Getränke" an den Bar-Drucker und "Speisen" an den Küchen-Drucker.
:::

### Drucker hinzufügen

Neue Küchendrucker werden in der mobilen App auf dem entsprechenden Gerät eingerichtet. Nach der Einrichtung erscheinen sie automatisch hier in der Liste.

## Tipps

- Änderungen werden automatisch gespeichert
- Testen Sie Druckereinstellungen nach der Konfiguration mit einem Testdruck
- Benutzer-Einstellungen ermöglichen individuelle Workflows für verschiedene Mitarbeiter
- Aktivieren Sie nur die Funktionen, die Sie wirklich benötigen - weniger ist oft mehr
