# Weitere Einstellungen

**Navigation:** Verwaltung → Weitere Einstellungen

Die weiteren Einstellungen ermöglichen es Ihnen, das Verhalten von Orderlyze an Ihre Bedürfnisse anzupassen. Die Einstellungen sind in zwei Bereiche unterteilt:

- **Allgemein** - Systemweite Einstellungen für alle Benutzer
- **Benutzer** - Individuelle Einstellungen pro Benutzer

:::info Küchen-Einstellungen
Die Einstellungen für Küchenbons finden Sie unter [Betrieb & Küche → Küchenbons](/betrieb/kuechenbons).
:::

![Einstellungen Übersicht](/screenshots/admin/einstellungen-uebersicht.png)

## Allgemeine Einstellungen

Die allgemeinen Einstellungen gelten für das gesamte System und alle Benutzer.

### Menüpunkte in der App

| Einstellung | Beschreibung |
|-------------|--------------|
| Einstellungen im Menü der App | Zeigt/versteckt die Einstellungen im App-Menü |
| Bankterminal in Einstellungen | Zeigt/versteckt die Bankterminal-Optionen |

### Hauptfunktionen

Hier können Sie verschiedene Systemfunktionen aktivieren oder deaktivieren:

| Funktion | Beschreibung |
|----------|--------------|
| Gängesystem | Ermöglicht die Zuweisung von Produkten zu Gängen |
| Stammkundensystem | Aktiviert die Kundenverwaltung |
| Gutscheinsystem | Ermöglicht das Erstellen und Einlösen von Gutscheinen |
| Onlineshop | Aktiviert die Onlineshop-Funktionalität |
| Tagesabschluss | Ermöglicht den täglichen Kassenabschluss |

![Hauptfunktionen](/screenshots/admin/einstellungen-hauptfunktionen.png)

### Zahlungsprozess

Einstellungen für den Bezahlvorgang wie Trinkgeldoptionen und Zahlungsarten.

### Produkte bonieren

Einstellungen für das Bonieren von Produkten in der App.

### Drucker

Konfiguration der Bondrucker und Druckoptionen.

### Umsatzauswertung

Einstellungen für die Darstellung von Umsatzberichten.

### Sonstige

Weitere allgemeine Einstellungen.

## Benutzer-Einstellungen

Die Benutzer-Einstellungen ermöglichen individuelle Konfigurationen für jeden Mitarbeiter.

1. **Benutzer auswählen** aus dem Dropdown-Menü
2. Gewünschte Einstellungen anpassen
3. Änderungen werden automatisch gespeichert

![Benutzer-Einstellungen](/screenshots/admin/einstellungen-benutzer.png)

Die verfügbaren Kategorien sind ähnlich wie bei den allgemeinen Einstellungen, aber die Werte gelten nur für den ausgewählten Benutzer.

## Einstellungen ändern

1. Navigieren Sie zu **Verwaltung → Weitere Einstellungen**
2. Wählen Sie den gewünschten Bereich (Allgemein oder Benutzer)
3. Klicken Sie auf eine Kategorie um sie aufzuklappen
4. Ändern Sie die gewünschten Einstellungen
5. Änderungen werden **automatisch gespeichert**

:::warning Wichtig
Einige Einstellungen erfordern einen Neustart der App auf den Geräten, damit sie wirksam werden.
:::
