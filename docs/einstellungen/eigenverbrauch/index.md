# Eigenverbrauch / Personalverbrauch

**Navigation:** Menü (oben rechts) → **Einstellungen** → **Eigenverbrauch / Personalverbrauch**

Hier legen Sie fest, wie Buchungen mit der Zahlart Eigenverbrauch bzw. Personalverbrauch bewertet werden. Der eingestellte Prozentsatz wird auf den Netto-Verkaufspreis angewendet und dient als geschätzter Einkaufspreis.

<BrowserFrame src="/screenshots/admin/einstellungen-eigenverbrauch.png" alt="Eigenverbrauch / Personalverbrauch Einstellungen" />

:::warning
Stimmen Sie die Prozentsätze und die Steuerbehandlung vorab mit Ihrer Steuerberatung ab.
:::

## Einstellungen

Eigenverbrauch und Personalverbrauch werden getrennt konfiguriert, die Felder sind identisch:

- **Prozentsatz vom Nettopreis** — Bleibt das Feld leer, gelten 100 % (voller Nettopreis). Der Prozentsatz greift nur, sofern am Produkt kein Einkaufspreis hinterlegt ist.
- **Steuerbehandlung** — Auswahl zwischen **0 % USt** und **Produktsteuersatz** (z. B. 10/20 %).
- **Sätze je Steuersatz** — Über **+ Steuersatz hinzufügen** können abweichende Prozentsätze für einzelne Steuersätze definiert werden.

Änderungen in jedem Bereich separat mit **Speichern** übernehmen.
