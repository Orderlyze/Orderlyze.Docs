# Logo

**Navigation:** Menü (oben rechts) → **Einstellungen** → **Logo**

Auf dieser Seite laden Sie das Firmenlogo hoch. Das Logo kann auf Rechnungen und Belegen angezeigt werden.

<BrowserFrame src="/screenshots/admin/einstellungen-logo.png" alt="Logo Einstellungen" />

:::warning Logo erscheint nicht auf der Rechnung?
Ein hochgeladenes Logo wird **nicht automatisch** auf Rechnungen gedruckt. Sie müssen zusätzlich den Schalter **"Logo auf Rechnung"** aktivieren.

Diesen Schalter finden Sie unter **Weitere Einstellungen**.

Wenn Sie also bereits ein Logo eingestellt haben, es aber auf der Rechnung fehlt, ist fast immer dieser Schalter noch nicht aktiviert.
:::

## So laden Sie ein Logo hoch

1. **Datei auswählen** klicken
2. Bilddatei (PNG/JPG) auswählen
3. **Speichern**

## So aktivieren Sie das Logo auf der Rechnung

Damit das hochgeladene Logo tatsächlich auf Rechnungen erscheint, aktivieren Sie zusätzlich den entsprechenden Schalter:

1. In die **Weitere Einstellungen** wechseln
2. Den Schalter **"Logo auf Rechnung"** aktivieren
3. **Speichern**

Ab sofort wird Ihr Logo auf neu erstellten Rechnungen mitgedruckt.

:::tip
Verwenden Sie eine hochauflösende Datei (mind. 300×300 px) mit transparentem Hintergrund, damit das Logo auf hellen und dunklen Druckvorlagen gut aussieht.
:::
