# Rechnung

**Navigation:** Test-Account-Menü (oben rechts) → **Einstellungen** → **Rechnung**

Hier legen Sie fest, wie Belege und Rechnungen für Endkunden aussehen — Rechnungsnummern, Kopf- und Fußtexte, Layout-Optionen.

![Rechnung Einstellungen](/screenshots/admin/einstellungen-rechnung.png)

## Typische Optionen

- **Rechnungsnummer-Format** (Präfix, Startzähler, Jahres-Reset)
- **Kopftext** / **Fußtext** auf dem Beleg
- **Hinweise** (z.B. Kleinunternehmerregelung, Rückgaberecht)
- **Steueranzeige** (Brutto / Netto getrennt)

Änderungen mit **Speichern** übernehmen.
