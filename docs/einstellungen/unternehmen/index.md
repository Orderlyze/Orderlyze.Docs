# Unternehmen

**Navigation:** Test-Account-Menü (oben rechts) → **Einstellungen** → **Unternehmen**

Auf dieser Seite hinterlegen Sie die Stammdaten Ihres Unternehmens. Diese Angaben erscheinen auf Rechnungen und werden vom System für Exporte und steuerliche Auswertungen verwendet.

![Unternehmen Einstellungen](/screenshots/admin/einstellungen-unternehmen.png)

## Felder

| Feld | Beschreibung |
|------|--------------|
| Unternehmensname * | Offizieller Name des Unternehmens (Pflichtfeld) |
| Umsatzsteuer-ID / Steuer-ID | USt-ID oder Steuernummer |
| E-Mail Adresse | Kontakt-E-Mail-Adresse |
| Telefon | Telefonnummer |
| Website | Webseite Ihres Unternehmens |
| Land | Sitzland — bestimmt Mehrwertsteuer-Vorgaben |
| Währung | Buchhaltungs-Währung (Standard: Euro) |

Änderungen mit **Speichern** übernehmen.
