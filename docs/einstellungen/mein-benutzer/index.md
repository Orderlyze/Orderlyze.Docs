# Mein Benutzer

**Navigation:** Menü (oben rechts) → **Mein Benutzer**

Hier verwalten Sie Ihr eigenes Benutzerkonto — unabhängig von der Benutzerverwaltung unter **Verwaltung → Benutzer**, in der Sie Konten für Ihre Mitarbeiter anlegen.

<BrowserFrame src="/screenshots/admin/mein-benutzer.png" alt="Mein Benutzer" />

## Übersicht

- **Account:** Benutzername, E-Mail-Adresse und Passwort
- **Details:** Geburtstag, Telefon und Datum der letzten Änderung

## Benutzer bearbeiten

Klick auf **Benutzer bearbeiten** → Änderungen vornehmen → **Speichern**

Bearbeitbare Felder: Vorname, Nachname, Benutzername, E-Mail-Adresse, Passwort, Geburtstag und Telefon.

Dabei gilt:

- Der **Benutzername** wird in der App verwendet und angezeigt.
- Die **E-Mail-Adresse** wird zum Anmelden in der App sowie in der Webanwendung benötigt.
- Das **Passwort** braucht mindestens 8 Zeichen mit Groß- und Kleinbuchstaben, Zahlen und Sonderzeichen.
