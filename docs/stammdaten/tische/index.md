# Tische

**Navigation:** Verwaltung → Tische

Tische sind die Grundlage für das Bonieren in der App: Bestellungen werden immer auf einen Tisch gebucht. Jeder Tisch gehört zu einem Raum.

<BrowserFrame src="/screenshots/admin/tische-liste.png" alt="Tische Übersicht" />

:::info
Bevor du Tische anlegen kannst, muss mindestens ein Raum existieren — der Raum ist beim Erstellen ein Pflichtfeld. Räume legst du unter **Verwaltung → Räume** an.
:::

## Tisch erstellen

1. Klick oben rechts auf **+ Tisch hinzufügen**
2. Pflichtfelder ausfüllen:
   - Name
   - Raum
3. **Speichern**

<BrowserFrame src="/screenshots/admin/tische-hinzufuegen-button.png" alt="Tisch hinzufügen Button" />

<BrowserFrame src="/screenshots/admin/tische-erstellen-dialog.png" alt="Tisch erstellen Dialog" />

## Tisch bearbeiten

Klick in der Zeile des Tisches auf das **Bearbeiten-Symbol** (Stift-Symbol rechts) → Änderungen vornehmen → **Speichern**

So kannst du einen Tisch auch nachträglich einem anderen Raum zuweisen.

<BrowserFrame src="/screenshots/admin/tische-bearbeiten-button.png" alt="Tisch bearbeiten Button" />

## Tisch löschen

Klick in der Zeile des Tisches auf das **Löschen-Symbol** (Mülleimer-Symbol ganz rechts) → Bestätigen.

<BrowserFrame src="/screenshots/admin/tische-loeschen-button.png" alt="Tisch löschen Button" />

:::tip
Die räumliche Anordnung der Tische (Tischplan) legst du nicht hier fest, sondern in der App per Tablet oder Smartphone — siehe **Funktionen → Tischplan**.
:::
