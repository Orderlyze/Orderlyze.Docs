# Produkte

**Navigation:** Verwaltung → Produkte

![Produkte Übersicht](/screenshots/admin/produkt-liste.png)

## Neues Produkt erstellen

1. Klick auf **+ Hinzufügen**
2. Pflichtfelder ausfüllen:
   - Name
   - Preis
   - Kategorie
3. **Speichern**

![Produkt erstellen](/screenshots/admin/produkt-erstellen-dialog.png)

## Produkt bearbeiten

Produkt in der Liste anklicken → Änderungen vornehmen → **Speichern**

## Produkt löschen

Produkt auswählen → **Löschen** → Bestätigen
