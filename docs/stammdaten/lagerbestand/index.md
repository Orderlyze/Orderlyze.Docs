# Lagerbestand

:::warning In Entwicklung
Dieses Feature befindet sich noch in Entwicklung und ist noch nicht für den produktiven Einsatz freigegeben.
:::

**Navigation:** Verwaltung → Lagerbestand

Übersicht über die Lagerbestände deiner Produkte.

<BrowserFrame src="/screenshots/admin/lagerbestand.png" alt="Lagerbestand Übersicht" />

## Spalten

| Spalte | Bedeutung |
|--------|-----------|
| **Name** | Produktname |
| **Aktueller Lagerbestand** | Derzeit verfügbare Menge |
| **Mindest Lagerbestand** | Untergrenze, die nicht unterschritten werden soll |
| **Meldebestand** | Bestand, ab dem nachbestellt werden sollte |
