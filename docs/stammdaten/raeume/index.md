# Räume

**Navigation:** Verwaltung → Räume

Räume gruppieren deine Tische — zum Beispiel Gastraum, Terrasse oder Bar. Jeder Tisch muss einem Raum zugeordnet sein, lege daher zuerst die Räume an.

<BrowserFrame src="/screenshots/admin/raeume-liste.png" alt="Räume Übersicht" />

## Raum erstellen

1. Klick oben rechts auf **+ Raum hinzufügen**
2. Pflichtfeld ausfüllen:
   - Name
3. **Speichern**

<BrowserFrame src="/screenshots/admin/raeume-hinzufuegen-button.png" alt="Raum hinzufügen Button" />

<BrowserFrame src="/screenshots/admin/raeume-erstellen-dialog.png" alt="Raum erstellen Dialog" />

## Raum bearbeiten

Klick in der Zeile des Raums auf das **Bearbeiten-Symbol** (Stift-Symbol rechts) → Änderungen vornehmen → **Speichern**

<BrowserFrame src="/screenshots/admin/raeume-bearbeiten-button.png" alt="Raum bearbeiten Button" />

## Raum löschen

Klick in der Zeile des Raums auf das **Löschen-Symbol** (Mülleimer-Symbol ganz rechts) → Bestätigen.

<BrowserFrame src="/screenshots/admin/raeume-loeschen-button.png" alt="Raum löschen Button" />

:::warning
Ein Raum lässt sich auch löschen, wenn ihm noch Tische zugeordnet sind — die Tische werden dabei **nicht** gelöscht, bleiben aber dem gelöschten Raum zugeordnet. Verschiebe die Tische deshalb vorher über **Verwaltung → Tische → Bearbeiten** in einen anderen Raum.
:::
