# Räume & Tische

## Räume

**Navigation:** Verwaltung → Räume

![Räume Liste](/screenshots/admin/raeume-liste.png)

### Raum erstellen

1. **+ Hinzufügen**
2. Name eingeben (z.B. "Terrasse", "Innen")
3. **Speichern**

## Tische

**Navigation:** Verwaltung → Tische

![Tische Liste](/screenshots/admin/tische-liste.png)

### Tisch erstellen

1. **+ Hinzufügen**
2. Tischnummer eingeben
3. Raum zuordnen
4. Plätze festlegen (optional)
5. **Speichern**
