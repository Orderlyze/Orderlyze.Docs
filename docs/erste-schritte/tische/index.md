# Tische

**Navigation:** Verwaltung → Tische

![Tische Übersicht](/screenshots/admin/tische-liste.png)

Hier verwalten Sie alle Tische Ihres Betriebs. Jeder Tisch wird einem Raum zugeordnet.

## Neuen Tisch erstellen

1. Klick auf **+ Tisch hinzufügen**
2. Namen eingeben (z.B. "Tisch 5")
3. Raum aus Dropdown wählen
4. **Speichern**

![Tisch erstellen](/screenshots/admin/tische-erstellen-dialog.png)

## Tisch bearbeiten

Klick auf das Bearbeiten-Symbol (Stift) in der Zeile des Tisches → Änderungen vornehmen → **Speichern**

![Tisch bearbeiten](/screenshots/admin/tische-bearbeiten.png)

## Tisch löschen

Klick auf das Löschen-Symbol (Mülleimer) in der Zeile des Tisches → Bestätigen

:::warning
Beim Löschen eines Tisches gehen alle zugehörigen Bestelldaten verloren. Stellen Sie sicher, dass keine offenen Bestellungen mehr auf diesem Tisch existieren.
:::

## Tipps

- Verwenden Sie eindeutige Namen für Ihre Tische
- Ordnen Sie Tische logisch nach Räumen
- Der "LIVE" Tisch wird für Echtzeit-Demos verwendet
