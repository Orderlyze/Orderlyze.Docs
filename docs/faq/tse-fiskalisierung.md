# Was ist TSE und ist es inklusive?

TSE (Technische Sicherheitseinrichtung) ist in Deutschland seit 2020 Pflicht für elektronische Kassensysteme. Orderlyze ist TSE-zertifiziert.

## Was ist TSE?

Die TSE ist eine technische Komponente, die:
- Jede Transaktion fälschungssicher speichert
- Einen QR-Code auf jeder Rechnung erstellt
- Die Daten für das Finanzamt bereitstellt

## Ist TSE bei Orderlyze inklusive?

**Ja.** Bei Orderlyze ist die TSE-Lösung im Abonnement enthalten. Sie müssen keine zusätzliche Hardware kaufen.

Orderlyze nutzt eine **Cloud-TSE**, die folgende Vorteile bietet:
- Keine zusätzliche Hardware nötig
- Automatische Updates
- Zentrale Verwaltung

## QR-Code auf der Rechnung

Der TSE-QR-Code wird automatisch auf jeder Rechnung gedruckt. Sie können dies in den Einstellungen konfigurieren:

1. **Verwaltung** → **Weitere Einstellungen** → **Allgemein**
2. Unter **Drucker** finden Sie: **Drucken von QRCode bei Fiskalierung Deutschland**
3. Aktivieren Sie diese Option

## Fiskalisierung in Österreich

In Österreich gilt die **Registrierkassenpflicht (RKSV)**. Orderlyze ist auch hier konform:

- Automatische Signierung jeder Rechnung
- Verbindung mit FinanzOnline
- QR-Code für Prüfung

Die Einrichtung erfolgt durch das Orderlyze-Team. Sie benötigen:
- Ihre FinanzOnline-Zugangsdaten
- Steuernummer

## Finanzamt-Prüfung

Bei einer Prüfung können Sie:
- Alle Daten exportieren
- Die TSE-Protokolle bereitstellen
- Tages-, Monats- und Jahresberichte vorlegen

## Wichtige Hinweise

- Die TSE muss bei jedem Kassenvorgang aktiv sein
- Bei Ausfall der Internetverbindung werden Transaktionen zwischengespeichert
- Die Daten werden automatisch nachsigniert sobald die Verbindung wiederhergestellt ist
