# Wie verbinde ich meinen Drucker?

Orderlyze unterstützt verschiedene Druckertypen. Die Verbindung erfolgt in der mobilen App.

## Unterstützte Druckertypen

- **Bluetooth-Drucker** - Kabellose Verbindung
- **WLAN-Drucker** - Verbindung über Netzwerk
- **Cloud-Drucker** - Drucken über Internet
- **Sunmi-Drucker** - Integrierte Drucker in Sunmi-Geräten

## Drucker verbinden

### Bluetooth-Drucker

1. Schalten Sie den Drucker ein
2. Aktivieren Sie Bluetooth auf Ihrem Gerät
3. Öffnen Sie die **Orderlyze App**
4. Gehen Sie zu **Einstellungen** in der App
5. Wählen Sie **Drucker**
6. Tippen Sie auf **Drucker hinzufügen**
7. Wählen Sie Ihren Drucker aus der Liste
8. Bestätigen Sie die Kopplung

### WLAN-Drucker

1. Verbinden Sie den Drucker mit Ihrem WLAN-Netzwerk
2. Stellen Sie sicher, dass Ihr Gerät im selben Netzwerk ist
3. Öffnen Sie die **Orderlyze App**
4. Gehen Sie zu **Einstellungen** → **Drucker**
5. Tippen Sie auf **Drucker hinzufügen**
6. Geben Sie die **IP-Adresse** des Druckers ein
7. Tippen Sie auf **Verbinden**

### Cloud-Drucker

Cloud-Drucker werden vom Orderlyze-Team eingerichtet. Kontaktieren Sie den [Support](mailto:support@orderlyze.com) für die Einrichtung.

## Druckereinstellungen aktivieren

Damit Sie Drucker hinzufügen können, müssen die entsprechenden Optionen im Web-Dashboard aktiviert sein:

1. Öffnen Sie das **Web-Dashboard**
2. Gehen Sie zu **Verwaltung** → **Weitere Einstellungen**
3. Wählen Sie **Allgemein**
4. Aktivieren Sie unter **Drucker**:
   - **Eigenen Drucker in Einstellungen hinzufügen**
   - **Bluetooth Drucker**
   - **Cloud Drucker**

## Testdruck durchführen

Nach dem Verbinden:

1. Gehen Sie zu **Einstellungen** → **Drucker** in der App
2. Wählen Sie den verbundenen Drucker
3. Tippen Sie auf **Testdruck**

## Häufige Probleme

### Drucker wird nicht gefunden

- Prüfen Sie ob der Drucker eingeschaltet ist
- Prüfen Sie ob Bluetooth/WLAN aktiviert ist
- Starten Sie den Drucker neu
- Starten Sie die App neu

### Verbindung bricht ab

- Prüfen Sie die Entfernung zum Drucker (Bluetooth: max. 10m)
- Prüfen Sie die WLAN-Signalstärke
- Entfernen Sie den Drucker und koppeln Sie ihn erneut
