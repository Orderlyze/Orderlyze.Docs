# Passwort vergessen - Wie kann ich mich anmelden?

Wenn Sie Ihr Passwort vergessen haben oder Probleme beim Anmelden haben, finden Sie hier Hilfe.

## Passwort zurücksetzen

1. Öffnen Sie die **Orderlyze Login-Seite**
2. Klicken Sie auf **Passwort vergessen?**
3. Geben Sie Ihre **E-Mail-Adresse** ein
4. Klicken Sie auf **Zurücksetzen**
5. Prüfen Sie Ihr E-Mail-Postfach
6. Klicken Sie auf den Link in der E-Mail
7. Geben Sie ein neues Passwort ein

## Passwort ändern (wenn eingeloggt)

1. Klicken Sie auf Ihren **Benutzernamen** (oben rechts)
2. Wählen Sie **Mein Benutzer**
3. Klicken Sie auf **Benutzer bearbeiten**
4. Scrollen Sie zum Bereich **Passwort**
5. Geben Sie das neue Passwort ein
6. Bestätigen Sie das neue Passwort
7. Klicken Sie auf **Speichern**

## Tipps für ein sicheres Passwort

- Mindestens 8 Zeichen
- Groß- und Kleinbuchstaben
- Mindestens eine Zahl
- Mindestens ein Sonderzeichen

## Häufige Login-Probleme

### "Daten sind nicht korrekt"

- Prüfen Sie die E-Mail-Adresse auf Tippfehler
- Achten Sie auf Groß-/Kleinschreibung beim Passwort
- Prüfen Sie ob die Feststelltaste (Caps Lock) aktiv ist

### Keine E-Mail zum Zurücksetzen erhalten

- Prüfen Sie den Spam-Ordner
- Warten Sie einige Minuten
- Versuchen Sie es erneut
- Kontaktieren Sie den [Support](mailto:support@orderlyze.com)

### Account gesperrt

Bei mehreren fehlgeschlagenen Login-Versuchen wird der Account vorübergehend gesperrt. Warten Sie einige Minuten und versuchen Sie es erneut.

## Benutzer für Mitarbeiter

Als Administrator können Sie neue Benutzer anlegen:

1. **Verwaltung** → **Benutzer**
2. Klicken Sie auf **+ Hinzufügen**
3. Geben Sie Name und E-Mail ein
4. Wählen Sie die Rolle (Admin, Kellner, Küche)
5. Klicken Sie auf **Speichern**

Der neue Benutzer erhält eine E-Mail zur Passwort-Erstellung.
