# Wie funktioniert Kartenzahlung mit Orderlyze?

Orderlyze bietet zwei Möglichkeiten für Kartenzahlung: Die integrierte Mollie-Lösung oder externe Kartenterminals.

## Option 1: Integrierte Mollie-Kartenzahlung

Orderlyze bietet eine integrierte Kartenzahlung über **Mollie**:

1. Gehen Sie zu **Kartenzahlung** im Hauptmenü
2. Geben Sie Ihre E-Mail-Adresse ein
3. Klicken Sie auf **Kartenzahlung einrichten**
4. Folgen Sie den Anweisungen zur Aktivierung

## Option 2: Externe Kartenterminals

Sie können auch separate Kartenterminals verwenden:

| Anbieter | Typ | Besonderheit |
|----------|-----|--------------|
| **SumUp** | Mobil | Günstig, keine monatlichen Kosten |
| **Zettle** | Mobil | Von PayPal, gute App |
| **Worldline** | Stationär | Für hohe Umsätze |
| **CCV** | Stationär | Klassisches EC-Terminal |

### Externes Terminal verwenden

1. Bestellen Sie ein Kartenterminal direkt beim Anbieter
2. Beim Kassieren: Wählen Sie **Kartenzahlung** als Zahlungsart
3. Geben Sie den Betrag am Terminal manuell ein
4. Kunde zahlt am Terminal
5. Bestätigen Sie die Zahlung in Orderlyze

## Ablauf einer Kartenzahlung

```
1. Kunde möchte mit Karte zahlen
2. In Orderlyze: Bestellung → Kassieren → Kartenzahlung wählen
3. Bei Mollie: Zahlung wird automatisch verarbeitet
   Bei externem Terminal: Betrag manuell eingeben
4. Kunde zahlt
5. Rechnung wird gedruckt
```

## Trinkgeld bei Kartenzahlung

Trinkgeld kann separat erfasst werden:

1. Bei der Zahlung **Trinkgeld-Betrag** eingeben
2. Oder: Trinkgeld später manuell erfassen
3. Trinkgeld erscheint im Tagesbericht

## Häufige Fragen

### Welche Gebühren fallen an?

Die Gebühren werden vom Zahlungsanbieter berechnet, nicht von Orderlyze. Typische Gebühren:
- EC-Karte: 0,9% - 1,5%
- Kreditkarte: 1,5% - 2,5%

### Kann ich mehrere Zahlungsarten kombinieren?

Ja, Sie können **Splitzahlung** nutzen:
1. Teil bar bezahlen
2. Rest mit Karte bezahlen

## Berichte

Kartenzahlungen werden in den Berichten separat ausgewiesen:
- **Tagesbericht**: Umsatz nach Zahlungsart
- **Zahlungsarten-Bericht**: Detaillierte Aufschlüsselung
