# Wie erstelle ich einen Tagesbericht?

Der Tagesbericht fasst alle Umsätze eines Tages zusammen. Sie können ihn im Web-Dashboard oder in der App erstellen.

## Automatischer Tagesabschluss

Orderlyze erstellt automatisch einen Tagesabschluss um **0:00 Uhr**. Sie müssen dafür nichts tun.

Die Uhrzeit können Sie anpassen unter:
**Verwaltung** → **Weitere Einstellungen** → **Allgemein** → **Tagesabschluss Zeitpunkt**

## Tagesbericht im Web-Dashboard

1. Melden Sie sich im **Web-Dashboard** an
2. Gehen Sie zu **Auswertungen** → **Tagesbericht**
3. Wählen Sie das gewünschte **Datum** (von - bis)
4. Klicken Sie auf **PDF Export herunterladen**
5. Die PDF-Datei wird generiert und heruntergeladen

## Tagesbericht in der App

1. Öffnen Sie die **Orderlyze App**
2. Tippen Sie auf das **Menü** (drei Striche)
3. Wählen Sie **Tagesabschluss** oder **Berichte**
4. Der Tagesbericht wird angezeigt und kann gedruckt werden

## Welche Daten enthält der Tagesbericht?

- Datum und Zeitraum
- Anzahl der Rechnungen
- Nettoumsatz
- Mehrwertsteuer
- Bruttoumsatz
- Aufschlüsselung nach Zahlungsarten (Bar, Karte, etc.)
- Trinkgeld
- Stornierungen

## Weitere Berichte

Neben dem Tagesbericht gibt es:

| Bericht | Beschreibung |
|---------|--------------|
| **Monatsbericht** | Umsätze eines Monats |
| **Jahresbericht** | Umsätze eines Jahres |
| **Produktbericht** | Meistverkaufte Produkte |
| **Zahlungsarten** | Umsätze nach Zahlungsart |

Alle Berichte finden Sie unter **Auswertung** im Web-Dashboard.

## Export für Buchhaltung

Tagesberichte können als **PDF** oder **CSV** exportiert werden. Der CSV-Export eignet sich für die Weiterverarbeitung in Excel oder Buchhaltungsprogrammen.
