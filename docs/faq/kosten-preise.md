# Was kostet Orderlyze?

Orderlyze bietet flexible Preismodelle für Gastronomiebetriebe jeder Größe.

## Preisübersicht

Die aktuellen Preise finden Sie auf unserer Website: [orderlyze.com/preise](https://orderlyze.com/preise)

Das Abonnement beinhaltet:
- Unbegrenzte Benutzer
- Alle Funktionen
- Cloud-TSE (Deutschland)
- RKSV-Konformität (Österreich)
- Updates & Support

## Kostenlose Demo

**Ja, Sie können Orderlyze kostenlos testen!**

1. Besuchen Sie [orderlyze.com](https://orderlyze.com)
2. Klicken Sie auf **Kostenlos testen**
3. Registrieren Sie sich mit Ihrer E-Mail
4. Testen Sie alle Funktionen 14 Tage lang

Während der Testphase:
- Voller Funktionsumfang
- Keine Kreditkarte nötig
- Keine automatische Verlängerung

|-----------|-----------------|
| ✅ Software-Lizenz | ❌ Hardware (Tablet, Drucker) |

| ✅ Updates | |

## Zusätzliche Hardware

Orderlyze läuft auf Ihren eigenen Geräten. Sie benötigen:

- **Tablet oder Smartphone** (iOS oder Android)
- **Bondrucker** (optional, für Rechnungsdruck)
- **Kartenterminal** (optional, für Kartenzahlung)

Hardwareempfehlungen finden Sie unter [Welches Gerät?](/faq/welches-geraet)

## Vertragslaufzeit

- Monatlich kündbar
- Keine lange Bindung
- Jährliche Zahlung mit Rabatt möglich
