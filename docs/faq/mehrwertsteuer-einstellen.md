# Wie stelle ich verschiedene MwSt-Sätze ein?

In der Gastronomie gelten in Deutschland unterschiedliche Mehrwertsteuersätze: **19%** für Verzehr im Haus und **7%** für Speisen zum Mitnehmen.

## MwSt-Satz pro Produkt

Jedes Produkt hat einen eigenen Mehrwertsteuersatz:

1. Gehen Sie zu **Verwaltung** → **Produkte**
2. Klicken Sie auf das Bearbeiten-Symbol neben einem Produkt
3. Wählen Sie im Feld **Mehrwertsteuer** den passenden Satz aus dem Dropdown:
   - Deutschland: MWST 19, MWST 7
   - Österreich: MWST 20, MWST 10
4. Klicken Sie auf **Speichern**

## Außer-Haus-Funktion (Deutschland)

Mit der Außer-Haus-Funktion können Sie beim Kassieren zwischen "Im Haus" und "Außer Haus" wählen:

### Aktivieren

1. Gehen Sie zu **Verwaltung** → **Weitere Einstellungen**
2. Wählen Sie **Allgemein**
3. Scrollen Sie zu **Zahlungsprozess**
4. Aktivieren Sie **Außer Haus Funktion**

### Verwendung

Beim Kassieren erscheint ein Button **Außer Haus**. Wenn aktiviert:
- Speisen werden mit 7% MwSt berechnet
- Der ermäßigte Satz wird auf der Rechnung ausgewiesen

## MwSt auf der Rechnung

Die Rechnung zeigt automatisch:
- Nettobetrag
- MwSt-Betrag (aufgeschlüsselt nach Sätzen)
- Bruttobetrag

Bei gemischten Bestellungen (z.B. 19% Getränke + 7% Speisen to-go) wird jeder Steuersatz separat ausgewiesen.

## Hinweis für Österreich

In Österreich gelten:
- **20%** Standard-MwSt
- **10%** ermäßigter Satz (Speisen)

Die Sätze werden automatisch angepasst wenn Sie Österreich als Land im Profil eingestellt haben.

## Finanzamt-Konformität

Orderlyze ist finanzamtkonform:
- Deutschland: TSE-Zertifizierung
- Österreich: Registrierkassenpflicht (RKSV)

Der QR-Code für die Fiskalierung wird automatisch auf der Rechnung gedruckt.
