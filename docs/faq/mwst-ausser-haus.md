# Wie stelle ich verschiedene MwSt-Sätze ein?

Für unterschiedliche MwSt-Sätze (Im Haus / Außer Haus) gibt es die **Außer Haus Funktion**.

Diese kann vom Support eingeschaltet werden. Danach bitte die **App neustarten**.
