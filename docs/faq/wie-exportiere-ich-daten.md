# Wie exportiere ich meine Daten?

Sie können Ihre Daten jederzeit aus Orderlyze exportieren. Diese Anleitung zeigt Ihnen wie.

## Verfügbare Export-Formate

- **CSV** - Für Excel, Google Sheets und andere Tabellenkalkulationen
- **PDF** - Für Berichte und Archivierung

## Daten exportieren

### Bestellungen exportieren

1. Öffnen Sie das **Dashboard** im Web
2. Navigieren Sie zu **Berichte** → **Bestellungen**
3. Wählen Sie den gewünschten Zeitraum
4. Klicken Sie auf **Exportieren**
5. Wählen Sie das Format (CSV oder PDF)

### Produkte exportieren

1. Gehen Sie zu **Einstellungen** → **Produkte**
2. Klicken Sie auf **Exportieren** (oben rechts)
3. Alle Produkte werden als CSV heruntergeladen

### Umsatzberichte exportieren

1. Öffnen Sie **Berichte** → **Umsatz**
2. Wählen Sie Zeitraum und Filter
3. Klicken Sie auf **Als PDF exportieren**

## Häufige Fragen

### Kann ich Daten importieren?

Ja, CSV-Imports für Produkte und Kategorien sind möglich. Kontaktieren Sie den Support für weitere Informationen.
