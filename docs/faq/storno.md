# Kann ich eine Rechnung stornieren?

Rechnungen können nicht gelöscht oder nachträglich geändert werden.

**Lösung:** Erstellen Sie eine neue Rechnung, in der Sie den Minusbetrag ausgleichen. Das ist für das Finanzamt in Ordnung.
