# Belege

:::warning In Entwicklung
Dieses Feature befindet sich noch in Entwicklung und ist noch nicht für den produktiven Einsatz freigegeben.
:::

**Navigation:** Belege

Nicht-fiskale Geschäftsdokumente erstellen und verwalten: **Angebote**, **Auftragsbestätigungen** und **Lieferscheine**.

<BrowserFrame src="/screenshots/rechnungen/belege.png" alt="Belege Übersicht" />

## Beleg erstellen

Oben rechts den gewünschten Belegtyp wählen — **Angebot**, **Auftragsbestätigung** oder **Lieferschein**. Der Editor entspricht dem von [Rechnung erstellen](/rechnungen/erstellen) (Empfänger, Positionen, Kopf-/Fußtext).

Ein Lieferschein kann auch direkt beim Erstellen einer Rechnung miterzeugt werden (Option **Lieferschein mit erstellen**).

## Übersicht filtern

Mit den Filter-Buttons **Alle / Angebot / Auftragsbestätigung / Lieferschein** die Liste auf einen Belegtyp eingrenzen.

:::info Nicht-fiskal
Belege sind keine Rechnungen — sie werden nicht signiert und nicht an das Finanzamt gemeldet. Aus einem Angebot wird erst mit [Rechnung erstellen](/rechnungen/erstellen) ein fiskalisches Dokument.
:::
