# Berichte

**Navigation:** Auswertung

Die Berichte-Funktion bietet Ihnen umfassende Einblicke in Ihre Geschäftsdaten. Sie können Tages-, Monats- und Jahresberichte erstellen sowie detaillierte Auswertungen zu Produkten, Kategorien, Zahlungsarten und mehr abrufen.

---

## Tagesbericht (Daily Report)

**Navigation:** Auswertung → Daily Report

![Tagesbericht](/screenshots/berichte/tagesbericht-uebersicht.png)

Der Tagesbericht fasst alle Umsätze eines bestimmten Tages zusammen und erstellt einen druckbaren PDF-Bericht.

### So erstellen Sie einen Tagesbericht:

1. Wählen Sie den gewünschten **Datumsbereich** aus (von - bis)
2. Klicken Sie auf **Download Daily Report(s)**
3. Die PDF-Datei wird generiert und heruntergeladen

:::tip
Sie können auch mehrere Tage auf einmal auswählen, um Berichte für einen längeren Zeitraum zu erstellen.
:::

---

## Monatsbericht (Monthly Report)

**Navigation:** Auswertung → Monthly Report

![Monatsbericht](/screenshots/berichte/monatsbericht-uebersicht.png)

Der Monatsbericht zeigt eine Übersicht aller Umsätze eines Monats.

### So erstellen Sie einen Monatsbericht:

1. Wählen Sie das **Jahr** aus dem Dropdown
2. Klicken Sie auf den gewünschten **Monat** (z.B. January, February, etc.)
3. Der Bericht wird automatisch generiert und heruntergeladen

---

## Jahresbericht (Yearly Report)

**Navigation:** Auswertung → Yearly Report

![Jahresbericht](/screenshots/berichte/jahresbericht-uebersicht.png)

Der Jahresbericht fasst alle Umsätze eines gesamten Jahres zusammen.

### So erstellen Sie einen Jahresbericht:

1. Wählen Sie das gewünschte **Jahr** aus dem Dropdown
2. Klicken Sie auf **Download**
3. Der Jahresbericht wird als PDF heruntergeladen

---

## Tagesumsatz (Daily Sale Report)

**Navigation:** Auswertung → More Reports → Daily Report

![Tagesumsatz](/screenshots/berichte/tagesumsatz-uebersicht.png)

Der Tagesumsatz-Bericht zeigt eine tabellarische Übersicht aller Tagesumsätze mit detaillierten Finanzinformationen.

### Angezeigte Informationen:

| Spalte | Beschreibung |
|--------|--------------|
| Date | Datum des Tages |
| Number of Invoices | Anzahl der erstellten Rechnungen |
| Net Amount | Nettobetrag |
| Value Added Tax | Mehrwertsteuer |
| Gross Amount | Bruttobetrag |

### Export-Optionen:

- **Download PDF** - Exportiert die Daten als PDF-Dokument
- **Download CSV** - Exportiert die Daten als CSV-Datei für weitere Verarbeitung

## Allgemeine Funktionen

### Datumsfilter

Alle Berichte außer Monats- und Jahresberichten verfügen über einen Datumsfilter:

1. Klicken Sie auf das **Kalender-Symbol**
2. Wählen Sie das **Startdatum**
3. Wählen Sie das **Enddatum**
4. Die Daten werden automatisch aktualisiert

### Anzahl der Einträge

Mit dem Dropdown **Show entries** können Sie festlegen, wie viele Einträge pro Seite angezeigt werden (10, 25, 50 oder 100).

### Sortierung

Klicken Sie auf die **Spaltenüberschriften**, um die Daten auf- oder absteigend zu sortieren.

### Export

Die meisten Berichte bieten zwei Export-Optionen:

- **Download PDF** - Für Ausdrucke und Dokumentation
- **Download CSV** - Für Import in Excel oder andere Programme

:::tip
CSV-Exporte eignen sich besonders gut für weitere Analysen in Tabellenkalkulationsprogrammen.
:::
