# Küchenmonitor

**Navigation:** Küche

![Küchen Monitor](/screenshots/kueche/monitor.png)

## Übersicht

Der Küchenmonitor zeigt alle offenen Bestellungen in Echtzeit.

## Bestellung abarbeiten

1. Bestellung wird angezeigt
2. Produkte zubereiten
3. **Fertig** klicken
4. Bestellung verschwindet

## Farbcodes

| Farbe | Bedeutung |
|-------|-----------|
| Weiß | Neue Bestellung |
| Gelb | > 5 Min wartend |
| Rot | > 10 Min wartend |
| Grün | Fertig |

## Einstellungen

Küchenmonitor-Einstellungen unter:
Administration → Einstellungen → Küche
