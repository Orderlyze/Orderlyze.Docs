# Extras

**Navigation:** Administration → Extras

![Extras Liste](/screenshots/admin/extras-liste.png)

## Was sind Extras?

Extras sind Zusatzoptionen für Produkte:
- Beilagen (Pommes, Salat)
- Größen (Klein, Mittel, Groß)
- Extras (Extra Käse, Ohne Zwiebeln)

## Extra erstellen

1. **+ Hinzufügen**
2. Name und Preis eingeben
3. Kategorie zuordnen (optional)
4. **Speichern**

## Extra einem Produkt zuweisen

Produkt bearbeiten → Extras Tab → Extras auswählen → **Speichern**
