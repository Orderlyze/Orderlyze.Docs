# Küchenbons

**Navigation:** Verwaltung → Weitere Einstellungen → Küche

Hier konfigurieren Sie die Ausgabe von Küchenbons und die Zuweisung von Druckern.

<BrowserFrame src="/screenshots/admin/einstellungen-kueche-details.png" alt="Küchenbons Einstellungen" />

## Einstellungen

| Einstellung | Beschreibung |
|-------------|--------------|
| Storno Belege Drucken | Druckt einen Bon bei Stornierungen |
| Cut nach jeden Gang | Schneidet das Papier nach jedem Gang |
| Bestellungen automatisch senden | Sendet Bestellungen automatisch an die Küche |
| Küchenzettel Schriftgröße | Klein oder Groß |
| Abstand vor der Bestellung | Platz vor dem Bestelltext |
| Abstand nach der Bestellung | Platz nach dem Bestelltext |
| Tisch/Kunden Transfer Belege drucken | Druckt Bons bei Tischwechsel |

## Drucker-Zuweisung

Jeder Drucker kann eigene Kategorien zugewiesen bekommen. So können z.B. Getränke an der Bar und Speisen in der Küche gedruckt werden.

<BrowserFrame src="/screenshots/admin/einstellungen-kuechenbons-drucker.png" alt="Drucker-Zuweisung" />

### Drucker aktivieren

1. Schalten Sie **Küchenbons drucken** ein (blauer Schalter)
2. Der Drucker empfängt nun Küchenbons

### Kategorien hinzufügen

1. Klicken Sie in das Dropdown-Feld unter dem Drucker
2. Wählen Sie die gewünschte Kategorie aus der Liste
3. Die Kategorie erscheint als Tag im Feld

### Kategorien entfernen

1. Klicken Sie auf das **×** neben der Kategorie
2. Die Kategorie wird sofort entfernt

:::tip Beispiel
- **Theken-Drucker**: Kategorie "Getränke" zuweisen
- **Küchen-Drucker**: Kategorie "Speisen" zuweisen

So werden Getränkebestellungen an der Theke und Speisebestellungen in der Küche gedruckt.
:::

## Einstellungen ändern

1. Navigieren Sie zu **Verwaltung → Weitere Einstellungen**
2. Wählen Sie den Tab **Küche**
3. Klicken Sie auf **Küchenbons** um die Einstellungen aufzuklappen
4. Ändern Sie die gewünschten Einstellungen
5. Änderungen werden **automatisch gespeichert**

:::warning Wichtig
Einige Einstellungen erfordern einen Neustart der App auf den Geräten, damit sie wirksam werden.
:::
