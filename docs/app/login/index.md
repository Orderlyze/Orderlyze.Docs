# Login

<img src="/screenshots/app/01_login.png" alt="Login Screen" width="280" />

Der Login-Screen ist der Einstiegspunkt der Orderlyze Mobile App.

---

## Anmeldung

1. **E-Mail-Adresse** eingeben
2. **Passwort** eingeben (Sichtbarkeits-Toggle verfügbar)
3. Auf **Einloggen** tippen

---

## Demo-Modus

Tippen Sie auf **Demo starten** um die App ohne Anmeldung zu testen. Der Demo-Modus zeigt alle Funktionen mit Beispieldaten.

---

## Weitere Optionen

| Element | Beschreibung |
|---------|--------------|
| Sichtbarkeits-Toggle | Passwort anzeigen/verbergen |
| Datenschutz | Link zur Datenschutzerklärung |
| AGB | Link zu den Allgemeinen Geschäftsbedingungen |
| Impressum | Link zum Impressum |
| Sprachauswahl | Sprache ändern (z.B. de-AT) |

---

## Probleme bei der Anmeldung?

- **Passwort vergessen:** Kontaktieren Sie [support@orderlyze.com](mailto:support@orderlyze.com)
- **Kein Zugang:** Wenden Sie sich an Ihren Administrator
