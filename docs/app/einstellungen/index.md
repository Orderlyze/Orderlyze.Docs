## Druckereinstellungen

<img src="/screenshots/app/14_druckereinstellungen.png" alt="Druckereinstellungen" width="280" />

**Navigation:** Einstellungen -> Druckereinstellungen

Konfigurieren Sie Ihren Bondrucker:

1. **Druckertyp ändern** Dropdown öffnen
2. Druckermodell auswählen (z.B. Epson 80)
3. **Speichern** tippen

:::info Unterstützte Drucker
- Epson (verschiedene Modelle)
- Star Micronics
- Weitere auf Anfrage
:::

## Logs {#logs}

<img src="/screenshots/app/12_logs.png" alt="Logs" width="280" />

**Navigation:** Seitenmenü -> Logs

Die Logs zeigen System-Protokolle für Fehleranalyse und Support:

### Filter-Optionen

| Filter | Beschreibung |
|--------|--------------|
| **Datumsfilter** | Start- und Enddatum für den Zeitraum |
| **Suchfeld** | Text in Logs suchen |
| **Typ-Dropdown** | Nach Log-Level filtern |

### Log-Einträge

Jeder Eintrag enthält:

- **Log-Level:** Information, Warning, Error
- **Zeitstempel:** Datum und Uhrzeit
- **Service-Quelle:** z.B. StorageService, HttpRequestHandler
- **Nachricht:** Details zum Ereignis

### Aktionen

| Icon | Funktion |
|------|----------|
| X | Logs löschen |
| Kopieren | Logs in Zwischenablage |
| Export | Logs exportieren |

:::tip Support-Anfragen
Bei Problemen können Sie die Logs exportieren und an den Support senden.
:::

Hier finden Sie alle rechtlichen Dokumente:
