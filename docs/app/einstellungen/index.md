# Einstellungen

<img src="/screenshots/app/06_settings.png" alt="Einstellungen" width="280" />

**Navigation:** Seitenmenü -> Einstellungen

Die Einstellungen sind Ihre zentrale Anlaufstelle für technische Konfigurationen der App. Hier richten Sie Ihren Bondrucker ein und können bei Bedarf alle Daten neu vom Server laden.

---

## Allgemeine Einstellungen

| Option | Beschreibung |
|--------|--------------|
| **Druckereinstellungen** | Öffnet die Drucker-Konfiguration. Hier wählen Sie Ihren Druckertyp aus (z.B. Epson 80, Star). |
| **Daten neu laden** | Synchronisiert alle Daten mit dem Server. Nutzen Sie dies, wenn neue Produkte oder Preisänderungen nicht angezeigt werden. |

:::tip Tipp
Wenn Sie bemerken, dass neue Produkte oder Preisänderungen nicht in der App erscheinen, tippen Sie auf "Daten neu laden". Die App holt sich dann die aktuellsten Informationen vom Server.
:::

:::info Tablet-Ansicht
Auf dem iPad wird das Seitenmenü dauerhaft angezeigt (Split-View). Sie können alle Einstellungen direkt aus dem Menü erreichen.

## Druckereinstellungen

<img src="/screenshots/app/14_druckereinstellungen.png" alt="Druckereinstellungen" width="280" />

**Navigation:** Einstellungen -> Druckereinstellungen

Auf dieser Seite konfigurieren Sie den Druckertyp für Ihren Bondrucker. Die richtige Einstellung ist wichtig, damit Ihre Rechnungen und Bestellbons korrekt gedruckt werden.

### Druckertyp ändern

| Element | Beschreibung |
|---------|--------------|
| **Druckertyp-Dropdown** | Tippen Sie darauf, um eine Liste aller unterstützten Druckermodelle zu sehen |
| **Speichern** (grün) | Speichert Ihre Druckerauswahl |

**So ändern Sie den Druckertyp:**

1. Tippen Sie auf das Dropdown-Feld mit dem aktuellen Druckertyp
2. Wählen Sie Ihren Drucker aus der erscheinenden Liste
3. Tippen Sie auf den grünen "Speichern"-Button

### Unterstützte Druckertypen

| Drucker | Beschreibung |
|---------|--------------|
| **Star** | Star-Bondrucker (z.B. Star TSP-Serie) |
| **Epson 80** | Epson TM-Serie mit 80mm Papierbreite |

:::info Hinweis zur Druckerverbindung
Die Druckereinstellungen legen nur den Druckertyp fest. Die eigentliche Verbindung zum Drucker (Bluetooth oder Cloud) richten Sie über das Drucker-Symbol in der Tischübersicht ein.
:::

### Cloud-Drucker

<img src="/screenshots/app/32_cloud_drucker_dialog.png" alt="Cloud-Drucker Dialog" width="280" />

**Navigation:** Drucker-Symbol -> Cloud

Cloud-Drucker sind über das Internet mit Ihrem Orderlyze-Konto verbunden. Sie können von überall drucken, solange eine Internetverbindung besteht.

**Wann brauchen Sie einen Cloud-Drucker?**

- Wenn Ihr Drucker nicht direkt per Bluetooth erreichbar ist
- Wenn mehrere Geräte auf denselben Drucker zugreifen sollen
- Wenn der Drucker in einem anderen Raum oder Netzwerk steht

**So richten Sie Ihren Cloud-Drucker ein:**

1. Tippen Sie auf das Dropdown-Feld "Wähle einen Drucker ..."
2. Wählen Sie den gewünschten Drucker aus der Liste
3. Tippen Sie auf "Speichern"

| Button | Beschreibung |
|--------|--------------|
| **Dropdown** | Zeigt alle verfügbaren Cloud-Drucker an |
| **Speichern** (grün) | Bestätigt Ihre Druckerauswahl |
| **Star Drucker hinzufügen** (blau) | Fügt einen neuen Star-Drucker hinzu |
| **X-Symbol** | Schließt den Dialog ohne Änderungen |

:::tip Tipp
Falls Ihr Drucker nicht in der Liste erscheint, prüfen Sie ob er eingeschaltet und mit dem Internet verbunden ist. Bei Problemen nutzen Sie "Star Drucker hinzufügen".
:::

### Star Drucker hinzufügen

**Navigation:** Drucker-Symbol -> Cloud -> Star Drucker hinzufügen

Star-Drucker sind professionelle Bondrucker für die Gastronomie. Sie können automatisch nach Star-Druckern in Ihrem Netzwerk suchen.

**So funktioniert's:**

1. Stellen Sie sicher, dass der Drucker eingeschaltet und im Netzwerk ist
2. Tippen Sie auf "Suche"
3. Wählen Sie den gefundenen Drucker aus der Liste
4. Der Drucker wird automatisch verbunden

| Button | Beschreibung |
|--------|--------------|
| **Suche** (blau) | Startet die automatische Druckersuche |
| **Pfeil zurück** | Kehrt zum vorherigen Bildschirm zurück |

### Drucker-Fehler beheben

<img src="/screenshots/app/36_drucker_fehler_dialog.png" alt="Drucker-Fehler Dialog" width="280" />

Dieser Dialog erscheint automatisch, wenn Sie versuchen zu drucken, aber kein Drucker verbunden ist.

**So lösen Sie das Problem:**

1. Tippen Sie auf "Okay" um den Dialog zu schließen
2. Tippen Sie auf das Drucker-Symbol (rechts oben auf der Tischübersicht)
3. Wählen Sie "Bluetooth" oder "Cloud"
4. Verbinden Sie einen Drucker
5. Versuchen Sie erneut zu drucken

## Kartenzahlung {#kartenzahlung}

**Navigation:** Seitenmenü -> Kartenzahlung

Die Kartenzahlung ermöglicht Ihnen, EC-Karten- und Kreditkartenzahlungen in Ihrem Betrieb anzubieten. Hier verbinden Sie Ihr Kartenzahlungsterminal mit der Orderlyze App.

:::info Tablet-Ansicht
<img src="/screenshots/app/tablet/11_kartenzahlung.png" alt="Kartenzahlung (Tablet)" width="500" />
:::

### Terminal verwalten

| Element | Beschreibung |
|---------|--------------|
| **Terminal-Dropdown** | Zeigt das aktuell verbundene Terminal an |
| **X-Symbol** | Entfernt das ausgewählte Terminal |
| **Bank Terminal hinzufügen** (blau) | Richtet ein neues Kartenzahlungsterminal ein |

### Terminal einrichten

<img src="/screenshots/app/20_terminal_hinzufuegen.png" alt="Terminal hinzufügen" width="280" />

**Navigation:** Kartenzahlung -> Bank Terminal hinzufügen

**So richten Sie ein neues Terminal ein:**

1. Tippen Sie auf "Bank Terminal hinzufügen"
2. Wählen Sie Ihren Terminal-Anbieter aus (z.B. Hobex, Mollie, ZVT, TECS)
3. Wählen Sie das passende Terminal-Modell
4. Tippen Sie auf das Häkchen-Symbol zum Speichern

| Element | Beschreibung |
|---------|--------------|
| **Anbieter** (Dropdown) | Liste aller unterstützten Terminal-Anbieter |
| **Model** (Dropdown) | Passende Terminal-Modelle je nach Anbieter |
| **Häkchen-Symbol** | Speichert das neue Terminal |
| **Zurück-Pfeil** | Bricht die Einrichtung ab |

### Unterstützte Terminal-Anbieter

| Anbieter | Beschreibung |
|----------|--------------|
| **Hobex** | Österreichischer Zahlungsdienstleister |
| **Mollie** | Europäischer Payment-Anbieter |
| **ZVT** | Standard-Protokoll für deutsche Kartenterminals |
| **TECS** | Terminal-System verschiedener Hersteller |

:::tip Tipp
Falls Sie nicht sicher sind, welchen Anbieter oder welches Modell Sie haben, finden Sie diese Information meist auf der Vorder- oder Rückseite Ihres Kartenterminals.
:::

## Logs {#logs}

<img src="/screenshots/app/12_logs.png" alt="Logs" width="280" />

**Navigation:** Seitenmenü -> Logs

Die Logs zeigen technische Protokolle der App an. Diese Informationen sind hauptsächlich für den Kundensupport gedacht, falls einmal etwas nicht wie erwartet funktioniert.

### Filter-Optionen

| Filter | Beschreibung |
|--------|--------------|
| **Suchfeld** | Text in Logs suchen |
| **Filter** | Grenzt die Protokolle nach Kriterien ein |

### Log-Einträge

Jeder Eintrag enthält:

- **Typ:** Information, Warning, Error
- **Zeitstempel:** Datum und Uhrzeit
- **Technische Details:** Informationen über App-Vorgänge im Hintergrund

### Aktionen

| Button | Beschreibung |
|--------|--------------|
| **X-Symbol** | Schließt die Logs-Ansicht |
| **Kopieren-Symbol** | Kopiert die Protokolle in die Zwischenablage |
| **Export-Symbol** | Exportiert die Logs als Datei |

:::tip Support-Anfragen
Bei Problemen exportieren Sie die Logs und senden Sie diese an support@orderlyze.com
:::
