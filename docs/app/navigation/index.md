# Navigation

![Seitenmenü](/screenshots/app/03_menu.png)

Das Seitenmenü erreichen Sie über das Hamburger-Icon (drei Striche) links oben in der Tischübersicht.

---

## Menüpunkte

| Menüpunkt | Beschreibung |
|-----------|--------------|
| **Hauptseite** | Zurück zur [Tischübersicht](/app/tischuebersicht) |
| **Benutzeransicht** | [Benutzerprofil & Einstellungen](/app/verwaltung#benutzeransicht) |
| **Rechnungsübersicht** | [Alle Rechnungen einsehen](/app/zahlung#rechnungsuebersicht) |
| **Verwaltung** | [Web-Portal für Admin-Funktionen](/app/verwaltung#web-portal) |
| **Tischplan gestalten** | [Tischlayout bearbeiten](/app/verwaltung#tischplan-editor) |
| **Kartenzahlung** | [Terminal-Einstellungen](/app/verwaltung#kartenzahlung) |
| **Einstellungen** | [App-Konfiguration](/app/einstellungen) |
| **Logs** | [System-Protokolle](/app/einstellungen#logs) |
| **Rechtliches** | [Impressum, Datenschutz, AGB](/app/einstellungen#rechtliches) |
| **Abmelden** | Session beenden und zum Login zurückkehren |

---

## Schnellzugriff

Die wichtigsten Funktionen sind auch direkt über die Toolbar der Hauptseite erreichbar:

- **Statistik-Icon:** Benutzer-Umsätze
- **Drucker-Icon:** Druckereinstellungen
