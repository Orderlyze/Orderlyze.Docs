**Navigation:** Seitenmenü → Verwaltung

Öffnet das Orderlyze Web-Portal direkt in der App für erweiterte Einstellungen und administrative Funktionen.

**Was Sie im Web-Portal tun können:**

- **Produkte verwalten:** Speisen und Getränke anlegen, Preise ändern
- **Kategorien bearbeiten:** Speisekarte organisieren
- **Firmendaten pflegen:** Adresse, Steuernummer, Logo aktualisieren
- **Mitarbeiter verwalten:** Neue Benutzerkonten erstellen
- **Berichte einsehen:** Detaillierte Umsatzberichte und Statistiken

**Browser-Navigation:**

| Button | Funktion |
|--------|----------|
| **Done** (oben links) | Schließt das Web-Portal |
| **Zurück-Pfeil** | Zur vorherigen Seite |
| **Vorwärts-Pfeil** | Zur nächsten Seite |
| **Teilen-Symbol** | Link teilen |
| **Neu laden** | Seite aktualisieren |

:::info Anmeldedaten
Sie verwenden für das Web-Portal dieselben Zugangsdaten wie für die Orderlyze App.
:::
