# Verwaltung

In diesem Bereich verwalten Sie Benutzer, den Tischplan, Zahlungsterminals und haben Zugriff auf Statistiken sowie den Tagesabschluss.

---

## Benutzeransicht {#benutzeransicht}

<img src="/screenshots/app/07_user_view.png" alt="Benutzeransicht" width="280" />

**Navigation:** Seitenmenü -> Benutzeransicht

In der Benutzeransicht sehen Sie Ihre persönlichen Kontoinformationen auf einen Blick. Hier verwalten Sie Ihr Benutzerkonto und können schnell zwischen verschiedenen Mitarbeitern wechseln.

**Ihre Kontoinformationen:**

- **Name:** Ihr vollständiger Name
- **Benutzername:** Ihr Kurzname im System
- **E-Mail-Adresse:** Die E-Mail, mit der Sie registriert sind

### Aktionen

| Button | Farbe | Funktion |
|--------|-------|----------|
| **Passwort ändern** | Grün | Passwort aktualisieren |
| **Benutzer wechseln** | Blau | Schneller Wechsel zu anderem Mitarbeiter-Konto |
| **Abmelden** | Rot | Sitzung beenden und zum Login zurückkehren |

:::tip Tipp für den Alltag
Nutzen Sie "Benutzer wechseln" anstatt "Abmelden", wenn mehrere Mitarbeiter am selben Gerät arbeiten. So geht der Wechsel schneller.
:::

:::info Tablet-Ansicht
Auf dem Tablet wird die Benutzeransicht im Split-View Layout angezeigt. Das Seitenmenü bleibt dabei sichtbar.

<img src="/screenshots/app/tablet/07_user_view.png" alt="Benutzeransicht (Tablet)" width="500" />
:::

### Passwort ändern {#passwort-aendern}

<img src="/screenshots/app/16_passwort_aendern.png" alt="Passwort ändern" width="280" />

**Navigation:** Benutzeransicht -> Passwort ändern

Ändern Sie Ihr persönliches Passwort für mehr Sicherheit.

**So ändern Sie Ihr Passwort:**

1. **Altes Passwort** eingeben
2. **Neues Passwort** eingeben (mindestens 8 Zeichen empfohlen)
3. **Passwort Bestätigung** eingeben
4. **Ändern** tippen

| Element | Beschreibung |
|---------|--------------|
| **Auge-Symbol** | Tippen Sie darauf, um das Passwort sichtbar zu machen |
| **Ändern** (grün) | Speichert das neue Passwort |
| **X-Symbol** | Schließt den Dialog ohne Änderung |

:::tip Tipps für ein sicheres Passwort
- Mindestens 8 Zeichen verwenden
- Groß- und Kleinbuchstaben, Zahlen und Sonderzeichen kombinieren
- Keine leicht zu erratenden Begriffe wie Namen oder Geburtsdaten
:::

### Benutzer wechseln {#benutzer-wechseln}

<img src="/screenshots/app/15_benutzer_wechseln.png" alt="Benutzer wechseln" width="280" />

**Navigation:** Benutzeransicht -> Benutzer wechseln

Dieser Dialog ermöglicht einen schnellen Wechsel zwischen Mitarbeiter-Konten ohne vollständiges Abmelden. Ideal bei Schichtwechsel.

**So wechseln Sie den Benutzer:**

1. **Benutzer** aus Dropdown auswählen
2. **Passwort** des gewählten Mitarbeiters eingeben
3. **Benutzer wechseln** tippen

| Button | Farbe | Funktion |
|--------|-------|----------|
| **Benutzer wechseln** | Grün | Bestätigt den Wechsel zum ausgewählten Benutzer |
| **X-Symbol** | - | Schließt den Dialog ohne Änderung |

:::warning Sicherheitshinweis
Geben Sie Ihr Passwort niemals an Kollegen weiter. Jeder Mitarbeiter sollte sein eigenes Passwort verwenden.
:::

## Web-Portal (Verwaltung) {#web-portal}

<img src="/screenshots/app/08_verwaltung.png" alt="Verwaltung Web-Portal" width="280" />

**Browser-Navigation:**

| Button | Funktion |
|--------|----------|

| **Zurück-Pfeil** | Zur vorherigen Seite |
| **Vorwärts-Pfeil** | Zur nächsten Seite |
| **Teilen-Symbol** | Link teilen |
| **Neu laden** | Seite aktualisieren |

:::info Anmeldedaten
Sie verwenden für das Web-Portal dieselben Zugangsdaten wie für die Orderlyze App.

## Tischplan-Editor {#tischplan-editor}

<img src="/screenshots/app/09_tischplan_editor.png" alt="Tischplan Editor" width="280" />

**Navigation:** Seitenmenü -> Tischplan gestalten

Gestalten Sie das Layout Ihrer Tische genau so, wie sie in Ihrem Restaurant stehen.

**Was Sie hier tun können:**

- **Tische anordnen:** Per Drag & Drop an die gewünschte Position ziehen
- **Neue Tische erstellen:** Über den Plus-Button hinzufügen
- **Räume verwalten:** Verschiedene Bereiche organisieren (z.B. Terrasse, Bar)
- **Tische bearbeiten:** Name, Größe und Ausrichtung anpassen

**Übersicht der Bereiche:**

| Bereich | Beschreibung |
|---------|--------------|
| **Rasterfläche** | Alle Tische des aktuellen Raums |
| **Schwarze Ränder** | Wände oder Raumgrenzen |
| **Blaue Tische** | Ihre Tische mit Namen |
| **Raum-Tabs** (unten) | Zwischen Räumen wechseln |

**Wichtige Buttons:**

| Button | Position | Funktion |
|--------|----------|----------|
| **Haken (✓)** | Oben rechts | Änderungen speichern |
| **Plus (+)** | Unten rechts | Neuen Tisch oder Trennlinie hinzufügen |

**So verschieben Sie einen Tisch:**

1. Tisch antippen und halten
2. An die neue Position ziehen
3. Loslassen
4. **Haken (✓)** zum Speichern tippen

:::warning Wichtig
Änderungen werden erst gespeichert, wenn Sie auf den Haken (✓) tippen. Ohne Speichern gehen alle Änderungen verloren.
:::

:::info Tablet-Ansicht
Auf dem Tablet haben Sie mehr Platz für die Tischplan-Gestaltung. Das Split-View Layout zeigt das Menü dauerhaft an.

<img src="/screenshots/app/tablet/09_tischplan_editor.png" alt="Tischplan Editor (Tablet)" width="500" />
:::

### Tisch hinzufügen {#tisch-hinzufuegen}

<img src="/screenshots/app/28_tisch_hinzufuegen.png" alt="Tisch hinzufügen" width="280" />

**Navigation:** Tischplan gestalten -> Plus-Button (+)

In diesem Dialog wählen Sie, ob Sie einen neuen Tisch oder eine Trennlinie hinzufügen möchten.

**Optionen:**

| Button | Funktion |
|--------|----------|
| **Neuer Tisch** (blau) | Öffnet Dialog für Tisch-Erstellung (Name, Größe) |
| **Neue Trennlinie** (blau) | Fügt eine visuelle Trennlinie hinzu |
| **X-Symbol** | Schließt den Dialog |

**So fügen Sie einen neuen Tisch hinzu:**

1. **Plus-Button** im Editor tippen
2. **Neuer Tisch** wählen
3. **Tischname** eingeben (z.B. "Fenster 1")
4. **Breite** festlegen (50-500)
5. **Höhe** festlegen (50-500)
6. **Hinzufügen** tippen
7. Tisch an gewünschte Position ziehen

:::tip Tipp
Benennen Sie Ihre Tische eindeutig, damit Ihre Mitarbeiter sie leicht finden (z.B. "Terrasse Links", "Fensterplatz").
:::

## Tagesabschluss {#tagesabschluss}

<img src="/screenshots/app/18_tagesabschluss.png" alt="Tagesabschluss" width="280" />

**Navigation:** Seitenmenü -> Tagesabschluss

Der Tagesabschluss ist Ihre zentrale Anlaufstelle für die tägliche Umsatzübersicht.

**Was Sie hier tun können:**

- **Umsätze einsehen:** Gesamtumsätze für einen frei wählbaren Zeitraum
- **Zeitraum wählen:** Start- und Enddatum festlegen
- **Abrechnungen prüfen:** Tägliche Einnahmen überprüfen

**Bedienelemente:**

| Element | Funktion |
|---------|----------|
| **"Von:" mit Datum** | Startdatum des Auswertungszeitraums |
| **"Bis:" mit Datum** | Enddatum des Auswertungszeitraums |
| **Liste der Abschlüsse** | Alle Tagesabschlüsse im gewählten Zeitraum |

**So wählen Sie einen Zeitraum:**

1. Auf Datum hinter "Von:" tippen
2. Startdatum festlegen
3. Auf Datum hinter "Bis:" tippen
4. Enddatum festlegen
5. Die Übersicht aktualisiert sich automatisch

**Die Abschlussliste zeigt:**

- Datum und Uhrzeit des Abschlusses
- Gesamtumsatz
- Tippen Sie auf einen Eintrag für Details

:::tip Tipp für den Alltag
Führen Sie am Ende jedes Arbeitstages einen Tagesabschluss durch, um Ihre Einnahmen zu dokumentieren.
:::

:::info Tablet-Ansicht
Auf dem Tablet wird der Tagesabschluss mit mehr Platz für die Liste dargestellt.

## Benutzer-Statistik {#benutzer-statistik}

<img src="/screenshots/app/tablet/19_benutzer_statistik.png" alt="Benutzer-Statistik" width="500" />

**Navigation:** Tischübersicht -> Statistik-Symbol (Diagramm-Symbol, oben rechts)

Die Benutzer-Statistik zeigt Ihnen die Umsätze Ihrer Mitarbeiter in einem bestimmten Zeitraum.

**Was Sie hier tun können:**

- **Umsätze pro Mitarbeiter einsehen:** Wie viel hat jeder Mitarbeiter erwirtschaftet
- **Zeitraum frei wählen:** Einzelne Tage, Wochen oder längere Zeiträume
- **Teamleistung vergleichen:** Umsätze verschiedener Mitarbeiter vergleichen
- **Gesamtsumme prüfen:** Summe aller Umsätze im gewählten Zeitraum

**Bedienelemente:**

| Element | Funktion |
|---------|----------|
| **"Von:" mit Datum** | Startdatum und -uhrzeit |
| **"Bis:" mit Datum** | Enddatum und -uhrzeit |
| **Mitarbeiterliste** | Alle Mitarbeiter mit ihren Umsätzen |
| **"Summe:"** | Gesamtumsatz im gewählten Zeitraum |
| **X-Symbol** | Dialog schließen |

**So wählen Sie einen Zeitraum:**

1. Auf Datumsfeld hinter "Von:" tippen
2. Datum im Kalender auswählen
3. Optional: Uhrzeit einstellen
4. Auf Datumsfeld hinter "Bis:" tippen
5. Enddatum festlegen
6. Umsätze werden automatisch berechnet

:::info Hinweis
Die angezeigten Umsätze basieren auf abgeschlossenen Rechnungen. Noch nicht abgerechnete Bestellungen werden nicht berücksichtigt.
:::

## Bearbeiten-Modus {#bearbeiten-modus}

<img src="/screenshots/app/29_bearbeiten_modus.png" alt="Bearbeiten-Modus" width="280" />

**Navigation:** Tischübersicht -> Tisch antippen -> Tab "Rechnung" -> Button "Bearbeiten"

Der Bearbeiten-Modus ermöglicht es Ihnen, bereits aufgenommene Bestellungen nachträglich zu korrigieren.

**Was Sie hier tun können:**

- **Mengen anpassen:** Anzahl einzelner Produkte erhöhen oder verringern
- **Produkte entfernen:** Einzelne Artikel löschen
- **Bestellung aufteilen:** Produkte zu einem anderen Tisch verschieben
- **Fehler korrigieren:** Eingabefehler schnell beheben

**Produktliste zeigt:**

- Produktname
- Menge (anpassbar mit +/-)
- Einzelpreis
- Gesamtpreis

**Buttons bei jedem Produkt:**

| Button | Farbe | Funktion |
|--------|-------|----------|
| **Minus (-)** | Rot | Menge um 1 verringern |
| **Plus (+)** | Grün | Menge um 1 erhöhen |
| **Stift-Symbol** | Grau | Weitere Bearbeitungsoptionen (Extras ändern) |

**Buttons am unteren Bildschirmrand:**

| Button | Farbe | Funktion |
|--------|-------|----------|
| **Alles löschen** | Weiß/Grau | ALLE Produkte entfernen |
| **Produkte transferieren** | Blau | Produkte zu anderem Tisch verschieben |
| **Bearbeiten beenden** | Rot | Modus schließen, Änderungen werden gespeichert |

:::warning Wichtig
Änderungen im Bearbeiten-Modus werden sofort gespeichert. Es gibt keine "Abbrechen"-Funktion. Entfernte Produkte müssen über "Hinzufügen" erneut hinzugefügt werden.
:::

Auf dem Tablet wird der Bearbeiten-Modus im Split-View angezeigt.
