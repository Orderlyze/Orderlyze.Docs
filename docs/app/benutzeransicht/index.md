**Navigation:** Seitenmenü → Benutzeransicht

In der Benutzeransicht sehen Sie Ihre persönlichen Kontoinformationen auf einen Blick. Hier verwalten Sie Ihr Benutzerkonto und können schnell zwischen verschiedenen Mitarbeitern wechseln.

**Ihre Kontoinformationen:**

- **Name:** Ihr vollständiger Name
- **Benutzername:** Ihr Kurzname im System
- **E-Mail-Adresse:** Die E-Mail, mit der Sie registriert sind

## Aktionen

| Button | Farbe | Funktion |
|--------|-------|----------|
| **Passwort ändern** | Grün | Passwort aktualisieren |
| **Benutzer wechseln** | Blau | Schneller Wechsel zu anderem Mitarbeiter-Konto |
| **Abmelden** | Rot | Sitzung beenden und zum Login zurückkehren |

:::tip Tipp für den Alltag
Nutzen Sie "Benutzer wechseln" anstatt "Abmelden", wenn mehrere Mitarbeiter am selben Gerät arbeiten. So geht der Wechsel schneller.
:::

## Passwort ändern {#passwort-aendern}

<img src="/screenshots/app/16_passwort_aendern.png" alt="Passwort ändern" width="280" />

**Navigation:** Benutzeransicht → Passwort ändern

Ändern Sie Ihr persönliches Passwort für mehr Sicherheit.

**So ändern Sie Ihr Passwort:**

1. **Altes Passwort** eingeben
2. **Neues Passwort** eingeben (mindestens 8 Zeichen empfohlen)
3. **Passwort Bestätigung** eingeben
4. **Ändern** tippen

| Element | Beschreibung |
|---------|--------------|
| **Auge-Symbol** | Tippen Sie darauf, um das Passwort sichtbar zu machen |
| **Ändern** (grün) | Speichert das neue Passwort |
| **X-Symbol** | Schließt den Dialog ohne Änderung |

:::tip Tipps für ein sicheres Passwort
- Mindestens 8 Zeichen verwenden
- Groß- und Kleinbuchstaben, Zahlen und Sonderzeichen kombinieren
- Keine leicht zu erratenden Begriffe wie Namen oder Geburtsdaten
:::

## Benutzer wechseln {#benutzer-wechseln}

<img src="/screenshots/app/15_benutzer_wechseln.png" alt="Benutzer wechseln" width="280" />

**Navigation:** Benutzeransicht → Benutzer wechseln

Dieser Dialog ermöglicht einen schnellen Wechsel zwischen Mitarbeiter-Konten ohne vollständiges Abmelden. Ideal bei Schichtwechsel.

**So wechseln Sie den Benutzer:**

1. **Benutzer** aus Dropdown auswählen
2. **Passwort** des gewählten Mitarbeiters eingeben
3. **Benutzer wechseln** tippen

| Button | Farbe | Funktion |
|--------|-------|----------|
| **Benutzer wechseln** | Grün | Bestätigt den Wechsel zum ausgewählten Benutzer |
| **X-Symbol** | - | Schließt den Dialog ohne Änderung |

:::warning Sicherheitshinweis
Geben Sie Ihr Passwort niemals an Kollegen weiter. Jeder Mitarbeiter sollte sein eigenes Passwort verwenden.
:::
