**Navigation:** Drucker-Symbol → Cloud

Cloud-Drucker sind über das Internet mit Ihrem Orderlyze-Konto verbunden. Sie können von überall drucken, solange eine Internetverbindung besteht.

**Wann brauchen Sie einen Cloud-Drucker?**

- Wenn Ihr Drucker nicht direkt per Bluetooth erreichbar ist
- Wenn mehrere Geräte auf denselben Drucker zugreifen sollen
- Wenn der Drucker in einem anderen Raum oder Netzwerk steht

**So richten Sie Ihren Cloud-Drucker ein:**

1. Tippen Sie auf das Dropdown-Feld "Wähle einen Drucker ..."
2. Wählen Sie den gewünschten Drucker aus der Liste
3. Tippen Sie auf "Speichern"

| Button | Beschreibung |
|--------|--------------|
| **Dropdown** | Zeigt alle verfügbaren Cloud-Drucker an |
| **Speichern** (grün) | Bestätigt Ihre Druckerauswahl |
| **Star Drucker hinzufügen** (blau) | Fügt einen neuen Star-Drucker hinzu |
| **X-Symbol** | Schließt den Dialog ohne Änderungen |

:::tip Tipp
Falls Ihr Drucker nicht in der Liste erscheint, prüfen Sie ob er eingeschaltet und mit dem Internet verbunden ist. Bei Problemen nutzen Sie "Star Drucker hinzufügen".
:::

## Star Drucker hinzufügen

  <figure className="device-figure">
    <img src="/screenshots/app/tablet/31_star_drucker_hinzufuegen.png" alt="Star Drucker hinzufügen (Tablet)" width="500" />
    <figcaption>Tablet</figcaption>

**Navigation:** Drucker-Symbol → Cloud → Star Drucker hinzufügen

Star-Drucker sind professionelle Bondrucker für die Gastronomie. Sie können automatisch nach Star-Druckern in Ihrem Netzwerk suchen.

**So funktioniert's:**

1. Stellen Sie sicher, dass der Drucker eingeschaltet und im Netzwerk ist
2. Tippen Sie auf "Suche"
3. Wählen Sie den gefundenen Drucker aus der Liste
4. Der Drucker wird automatisch verbunden

| Button | Beschreibung |
|--------|--------------|
| **Suche** (blau) | Startet die automatische Druckersuche |
| **Pfeil zurück** | Kehrt zum vorherigen Bildschirm zurück |

**Navigation:** Drucker-Symbol → Bluetooth

Verbinden Sie einen portablen Bluetooth-Drucker für den mobilen Einsatz (z.B. am Tisch drucken).

**So funktioniert's:**

1. Schalten Sie den Bluetooth-Drucker ein
2. Aktivieren Sie Bluetooth auf Ihrem Gerät
3. Geben Sie einen Namen für den Drucker ein
4. Tippen Sie auf "Hinzufügen"

| Button | Beschreibung |
|--------|--------------|
| **Hinzufügen** (blau) | Verbindet den Bluetooth-Drucker |
| **X-Symbol** | Schließt den Dialog |

Dieser Dialog erscheint automatisch, wenn Sie versuchen zu drucken, aber kein Drucker verbunden ist.

**So lösen Sie das Problem:**

1. Tippen Sie auf "Okay" um den Dialog zu schließen
2. Tippen Sie auf das Drucker-Symbol (rechts oben auf der Tischübersicht)
3. Wählen Sie "Bluetooth" oder "Cloud"
4. Verbinden Sie einen Drucker
5. Versuchen Sie erneut zu drucken
